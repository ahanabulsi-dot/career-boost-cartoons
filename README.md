# Career Boost cartoons

Twelve looping, hand-drawn cartoon GIFs used as the image panels in a weekly newsletter email.

- 24fps, animated on twos (a new drawing every 2 frames)
- Line boil: every line cycles through 3 jitter variants
- Palette: off-white #fffaf0, ink #1c1c1c, flat fills #ff595e #1982c4 #ffca3a, stamps #ff2e63

## Weekly renders

The weekly emails use files named `<scene>__<stamp>.gif`, rendered by the newsletter's routine. The stamp text changes per issue, and new scenes are added when a story needs one. Existing files are reused rather than re-rendered.
